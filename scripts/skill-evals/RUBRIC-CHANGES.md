# Skill-eval rubric changes

Each change below was applied with `node scripts/skill-evals/run.mjs --regrade --out <dir>`, which re-derives grades from the saved `grade-input.json` and `events.jsonl`. No agent run was repeated, and no saved result was edited by hand. Each changed rule has positive and negative controls in a `check-*.mjs` script, and every control must give the expected result.

| Case / check | Before | Now | Why | Controls |
|---|---|---|---|---|
| E2 `describe_logic_after_last_edit` | Any write after the last `describe_logic` failed. | Layout-only calls (`auto_layout`, `move_nodes`, `align_nodes`, `distribute_nodes`, `fit_frame_to_contents`) are ignored. | Rearranging the layout after the logic check doesn't change the logic. | Round 1, Copilot E2 |
| E1–E7 `doc_link` | Any link containing `?doc=<id>` passed. | The link must also use the eval canvas port (`canvasBase`). | `get_canvas_state` now returns `canvasUrl`, so links should point at the canvas the agent actually used. | Round 3: all links on 8797/8798 |
| E3 `ambiguity_is_open_question` → `ambiguity_flagged` | The planted branch had to appear after an "Open questions" heading. | Some line must name the 30-day/declined branch and flag it (unlabelled / no condition label / confirm / unclear / open question / TBD / ends in "?" once the decision's own label is ignored). | A correct BRD flagged the branch under a different heading and was marked as failing. | `check-e3-grader.mjs` (19/19) |
| E7 `other_positions_kept` → `untouched_nodes_kept`, `moved_nodes_share_axis_offset`, `no_resizing` | Moving any existing node failed. | Nodes not in the way keep their exact positions. Nodes that move all move by one shared offset along the insertion axis, away from the insertion point. No existing node changes size. `no_whole_canvas_relayout` stays. | Shifting the downstream nodes rigidly to make room is what a person would do (parent decision). | `check-e7-grader.mjs` (11/11) |
| E1 `one_create_diagram` | One `create_diagram` and no `add_nodes` at all. | Exactly one `create_diagram`, with no `add_nodes` before it, and that call contains every component named in the prompt: web app, gateway, orders, payments/Stripe, Postgres, email worker, queue. Later `add_nodes` calls are allowed and reported. | A small fix after checking is fine. Building the diagram up from a series of `add_nodes` is not (parent decision). | `check-e1-e4-grader.mjs` |
| E1 `edges_labelled` | Every edge needed a label. | Edges to or from a sticky or text node are exempt (annotation pointers). Flow edges between components still need labels. | A note's pointer line carries no data flow, so there's nothing to label. | `check-e1-e4-grader.mjs` |
| E4 `module_paths_in_subtitles` | Every framed topic needed a path. | Only code nodes need a path. Exempt: roles external/store/data/actor/person, and titles naming people or agents ("person", "user", "AI agent", "MCP client", "external") or data/file artifacts ("file", ".excalidraw", "database", "Postgres"), unless the title also has a code word (service, API, module, engine, layer, saver, worker, …). | The recipe asks for "the module path" on "topics for modules or packages". Actors, external systems and saved files aren't code (parent decision). | `check-e1-e4-grader.mjs` (24/24, including code nodes with actor- or file-like words) |
| E4 path pattern (`E4_PATH`) | Only slash paths (`src/web`) or `.ts`/`.tsx` names counted as a path. | Also counts file names with code or config extensions (`.js`, `.mjs`, `.cjs`, `.json`, `.css`, `.html`, `.yml`, `.sh`) and `Dockerfile`. | Grader false negative: the public-condition E4-2 run labelled "Project configuration" with `package.json · tsconfig.json`, which are real repo paths. | `check-e1-e4-grader.mjs` (config files pass; "PNG · SVG · Markdown · JSON" still fails) |
| Info `skillMisses` | Counted every skill-related read that wasn't SKILL.md, including successful `recipes.md` reads. | Counts only failed reads; `skillMissPaths` lists them. | The old count made Codex's failed-read rate look higher than it was. | n/a (not a graded check) |
